Diagnostic report

Run it when your printer is new or untested, a feature or metric is missing, a value is wrong, or the exporter does not connect. Then copy or download it, or create a GitHub issue with it, so support can be added or fixed without access to your printer.

Removed from the report: access codes, tokens, serial numbers (except the 3-character model prefix), IP and MAC addresses, Wi-Fi and printer names, job and file names, account ids and emails. Check it before you share it. Running it sends nothing to the printer. More about the report

Tip: run it while the problem shows (during a print, while drying, with the accessory fitted).
